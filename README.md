## 📌 Overview

DataPilot is a web-based data analytics application that allows users to work with different data formats and explore their datasets through an interactive interface.

It supports:

* CSV files
* Excel files
* JSON files

## ✨ Key Highlights

* Multiple file format support.
* Interactive data exploration.
* Full-stack web application architecture.
* Python-based backend processing.
* Modern React frontend.

## 🛠️ Technology Stack

| Layer           | Technology      |
| --------------- | --------------- |
| Frontend        | React           |
| Backend         | Python, FastAPI |
| Data Processing | Pandas, NumPy   |
| Database        | MySQL           |


Move into the project directory:

```bash

```

Follow the frontend and backend installation instructions in their respective project directories.

The objective of DataPilot is to provide an accessible platform for working with structured data and exploring useful information from different file formats.
